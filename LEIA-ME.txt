UPLOAD NO GITHUB
1. Extraia o ZIP.
2. No repositório, escolha Add file > Upload files.
3. Envie os arquivos desta pasta para a raiz, substituindo os arquivos de mesmo nome.
4. Clique em Commit changes e aguarde o GitHub Pages publicar.
